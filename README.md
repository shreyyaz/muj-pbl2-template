# MUJ PBL-2 Presentation Template

A clean and responsive presentation template designed for Project-Based Learning (PBL-2) submissions at Manipal University Jaipur. The project provides a lightweight and customizable HTML based presentation interface for academic project submissions.

## Live Demo

https://pbl2-temp.vercel.app

## Features

- Responsive HTML presentation layout
- Simple and lightweight design
- MUJ branding support
- Ready-to-use PBL presentation structure
- Easy customization for academic projects
- Browser-based presentation access

## Tech Stack

- HTML5
- CSS3
- Vercel Deployment

## Project Structure

```bash
├── index.html                  # Main homepage
├── pbl_ppt_template.html       # Presentation template
├── mujlogo.jpg                 # MUJ logo asset
├── PBL-2 PPT Sample.pptx       # Sample PPT file
└── README.md
```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/shreyyaz/muj-pbl2-template.git
```

Open the project folder:

```bash
cd muj-pbl2-template
```

Run locally by opening:

```bash
index.html
```

## Deployment

The project is deployed using Vercel for fast and reliable hosting.
